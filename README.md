# PetShoop


`PROJETO DE DESENVOLVIMENTO FULLSTACK`


## 🐾 PetShop

PetShop é uma API desenvolvida para gerenciar de forma centralizada os principais processos de um pet shop, conectando clientes, seus animais de estimação, funcionários, serviços e produtos em um único sistema.

A plataforma permite cadastrar clientes e seus pets, mantendo informações como espécie, raça, peso, histórico de vacinação e dados do animal. Os clientes podem realizar agendamentos de serviços, como banho, tosa e outros atendimentos, selecionando o serviço, o pet, o funcionário responsável e o horário desejado.

Para os funcionários, o sistema oferece recursos para gerenciamento de agendamentos e consultas veterinárias, permitindo registrar informações como diagnóstico, prescrição, peso, temperatura e observações do atendimento. O sistema também mantém o histórico do pet, facilitando o acompanhamento de seus atendimentos e cuidados ao longo do tempo.

Além dos serviços, o PetShop possui um módulo de vendas, permitindo cadastrar produtos, controlar estoque e registrar vendas realizadas pelos clientes. Cada venda pode conter diversos produtos, com informações de quantidade e valor unitário.

O sistema busca proporcionar uma gestão mais organizada e eficiente para o estabelecimento, centralizando clientes, pets, funcionários, serviços, agendamentos, consultas, vacinas, produtos, estoque e vendas em uma única aplicação.


### Principais funcionalidades
* 👤 Cadastro e gerenciamento de clientes
* 🐶 Cadastro e gerenciamento de pets
* 👨‍⚕️ Gerenciamento de funcionários
* ✂️ Cadastro de serviços
* 📅 Agendamento de serviços
* 🩺 Registro de consultas veterinárias
* 💉 Controle de vacinas
* 📋 Histórico/prontuário dos pets
* 📦 Cadastro e controle de produtos
* 🛒 Registro de vendas
* 💰 Controle de valores e formas de pagamento
* 📊 Controle de estoque
